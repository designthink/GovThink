# GovThink

Example of how ChatGPT Pro and Gemini Pro analyze the differences between the New Zealand and Finland
government systems.

The current materials compare each model's output on the same topic:

- ChatGPT Pro government-structure comparison PDF
- ChatGPT Pro government-structure diagram PNG
- Gemini Pro government-structure comparison PDF
- Gemini Pro government-structure diagram PNG

## Purpose

The experiment is intended to compare the substance, framing, and visual communication of each model's research output. The focus is not only whether the answers are correct, but also how clearly each model explains structural differences between the two systems of government.
